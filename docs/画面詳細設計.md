# チェックリスト一覧画面
* 新規追加ボタン
    * 追加編集画面に遷移する
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 常時活性させる
* 削除ボタン
    * クリックすると削除APIを実行する
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 一覧のどれか一つにチェックがついたら活性化する
* キーワード検索
    * 文字を入力して検索ボタンを押すとキーワードに部分一致する名前のチェックリストを一覧に出す
    * 検索ボタンをクリックすると振動する
    * 検索ボタンにカーソルを当てると薄灰色になる
* ページ遷移ボタン
    * 「<」をクリックするとページ数を-1して前の10個を一覧取得する
    * 「>」をクリックするとページ数を+1して次の10個を一覧取得する
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
* チェックリストテーブル
    * カーソルを当てると青色になる
    * クリックするとチェックリスト画面に遷移する
    * クリックすると振動する
    * チェックボックスをクリックすると選択状態になる

# チェックリスト追加編集画面
* 追加画面
    * クリックすると新しいテキスト項目が増える
    * クリックすると振動する
    * カーソルを当てると青くなる
    * 常時活性状態
* 削除ボタン
    * クリックするとテキスト項目が削除される
    * クリックすると振動する
    * カーソルを当てると赤くなる
    * 常時活性状態
* 保存ボタン
    * クリックすると追加編集APIを実行する
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 常時活性状態
    * 項目が0個の状態でクリックすると「項目を追加してください」という赤文字のテキストがボタンの下に出る
* 戻るボタン
    * クリックするとチェックリスト画面に戻る
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 常時活性状態

# チェックリスト画面
* 一覧に戻るボタン
    * クリックすると一覧に戻る
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 常時活性状態
* 編集ボタン
    * クリックすると追加編集画面に遷移する
    * クリックすると振動する
    * カーソルを当てると薄灰色になる
    * 常時活性状態
* チェックリスト
    * チェックボックスまたは名前をクリックするとチェックがつく
    * チェックがつくと青色に変化する
    * 進捗率は「(チェック項目/全体数)%」とする
